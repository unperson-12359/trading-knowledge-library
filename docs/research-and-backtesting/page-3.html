    Ensemble model #

    A predictor that combines outputs from multiple component models to improve stability, accuracy, or coverage of different patterns.
    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: Train diverse base estimators and aggregate their predictions by averaging, voting, weighted blending, or a learned meta-model.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.
    Misconceptions: Greater model complexity or in-sample accuracy does not by itself imply better out-of-sample trading results.
    Example: Three return forecasts of 0.2%, -0.1%, and 0.5% are equally averaged into a 0.2% ensemble forecast.

    Bagging #

    An ensemble method that fits base estimators independently on resampled observations or features and averages or votes their predictions.
    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: Draw bootstrap samples, train one base model per sample, obtain predictions from all models, and aggregate them.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.
    Misconceptions: Greater model complexity or in-sample accuracy does not by itself imply better out-of-sample trading results.
    Example: One hundred trees trained on bootstrap samples vote 62 to 38 for the positive class.

    Boosting #

    An additive ensemble method that trains weak learners sequentially so later learners emphasize errors or negative gradients left by the current ensemble.
    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: Initialize a prediction, fit a learner to weighted errors or loss gradients, scale its contribution, and add it to the ensemble repeatedly.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.
    Misconceptions: Greater model complexity or in-sample accuracy does not by itself imply better out-of-sample trading results.
    Example: A second stump focuses on observations misclassified by the first and its weighted vote is added to the score.

    Random forest #

    A bagged ensemble of decision trees that also randomizes the candidate features considered at splits, reducing correlation among trees.
    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: Bootstrap rows for each tree, choose splits from random feature subsets, grow many trees, then average regression values or vote on classes.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.
    Misconceptions: Greater model complexity or in-sample accuracy does not by itself imply better out-of-sample trading results.
    Example: Five hundred trees each consider sqrt(p) features per split; 310 vote for an up day, producing class 1.

    Gradient boosting #

    Boosting that adds weak learners fitted to the negative gradient of a differentiable loss with respect to current predictions.
    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: Compute current predictions and loss gradients, fit a small tree to those gradients, scale it by a learning rate, and add it to the model.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.
    Misconceptions: Greater model complexity or in-sample accuracy does not by itself imply better out-of-sample trading results.
    Example: A regression tree fitted to residual-like gradients is multiplied by 0.05 and added as iteration 20.

    XGBoost #

    A scalable gradient-tree-boosting system using a regularized objective, second-order loss approximation, sparsity-aware split handling, and optimized tree construction.
    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: At each boosting round, use gradients and Hessians to choose tree splits and leaf weights, add the regularized tree, and update predictions.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.
    Misconceptions: Greater model complexity or in-sample accuracy does not by itself imply better out-of-sample trading results.
    Example: A binary classifier adds 200 shallow trees at learning rate 0.05 and converts the summed margin through a logistic link.
    Prediction = sum of tree leaf scores; objective = loss + sum of tree penalties

    Recurrent neural network #

    A neural network for sequences that updates a hidden state from the current input and previous state, sharing parameters across time steps.
    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: Process observations in order using h_t = activation(W_x x_t + W_h h_previous + b), then map states to outputs and train through time.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.
    Misconceptions: Greater model complexity or in-sample accuracy does not by itself imply better out-of-sample trading results.
    Example: A 30-day return sequence updates one hidden state per day and the final state predicts day 31 direction.
    h_t = f(W_x x_t + W_h h_(t-1) + b)

    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.

    Intuition: It is a learnable mapping or representation used to turn features into predictions or groups.
    Mechanics: Initialize k centroids, alternate nearest-centroid assignment and centroid recomputation, and stop when assignments or inertia stabilize.
    Failure modes: Flexible models can fit noise, shift under new regimes, and conceal instability when tuning is repeated on the same validation data.

    Confusion matrix #

    A table counting predicted classes against actual classes, including true positives, false positives, true negatives, and false negatives for binary outcomes.
    Intuition: It summarizes one aspect of prediction error or decision quality in a number or curve.
    Mechanics: Apply a fixed decision threshold to held-out scores, cross-tabulate predictions and labels, and derive threshold-dependent classification metrics from the counts.

    Precision #

    Intuition: It summarizes one aspect of prediction error or decision quality in a number or curve.
    Mechanics: Count true and false positives at a specified threshold and divide true positives by all predicted positives.

    F1 score #

    The harmonic mean of precision and recall, balancing the two when both are important.
    Intuition: It summarizes one aspect of prediction error or decision quality in a number or curve.
    Mechanics: Compute precision and recall from held-out classifications and take twice their product divided by their sum.
    Failure modes: Class imbalance, threshold choice, unequal error costs, outliers, and dependence can make the summary inappropriate or unstable.
    Misconceptions: No single metric captures economic utility, turnover, risk, calibration, and trading costs at once.
    Example: Precision 0.75 and recall 0.60 give F1 = 0.667.
    F1 = 2 precision recall / (precision + recall)

    ROC curve #

    A threshold curve plotting true-positive rate against false-positive rate for a binary score.
    Intuition: It summarizes one aspect of prediction error or decision quality in a number or curve.
    Mechanics: Sort distinct score thresholds, classify observations at each threshold, and plot recall against one minus specificity.
    Failure modes: Class imbalance, threshold choice, unequal error costs, outliers, and dependence can make the summary inappropriate or unstable.
    Misconceptions: No single metric captures economic utility, turnover, risk, calibration, and trading costs at once.
    Example: Lowering a threshold raises TPR from 0.60 to 0.80 while FPR rises from 0.10 to 0.25, adding a point to the ROC curve.
    TPR = TP/(TP+FN); FPR = FP/(FP+TN)
