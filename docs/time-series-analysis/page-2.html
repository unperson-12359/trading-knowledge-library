    EGARCH model reviewed #

    Exponential GARCH: Nelson's (1991) model of the log conditional variance as a function of past standardized innovations with separate magnitude and sign terms, guaranteeing positive variance without parameter constraints and capturing the asymmetric (leverage) response of volatility to negative shocks.
    Intuition: Because it models log variance, the variance can never go negative, and the sign term lets bad news lift volatility more than good news of the same size, matching the leverage effect in equity returns.
    Mechanics: EGARCH(1,1) sets log sigma_t^2 = omega + beta log sigma_{t-1}^2 + alpha (|z_{t-1}| - E|z_{t-1}|) + gamma z_{t-1} with standardized innovation z_t = epsilon_t / sigma_t, estimated by maximum likelihood; gamma < 0 produces higher volatility after negative shocks, and the log form needs no non-negativity constraints.
    Failure modes: Because variance enters in logs, the model is sensitive to very small standardized residuals and estimation is less stable than for plain GARCH; forecasts of variance (not log variance) need exponentiation with Jensen-inequality corrections. It shares GARCH's sensitivity to structural breaks.
    Misconceptions: That the asymmetry term measures skewness of returns: it measures the asymmetric impact of signed innovations on future variance, distinct from unconditional skewness.
    Example: Nelson applied EGARCH to U.S. stock returns and found a negative sign coefficient: a negative return shock raises next-period variance substantially more than an equal positive shock.
    ln sigma_t^2 = omega + beta ln sigma_{t-1}^2 + alpha (|z_{t-1}| - E|z_{t-1}|) + gamma z_{t-1}, z_t = epsilon_t / sigma_t; gamma < 0 gives the leverage effect.
    Aliases: exponential GARCH, EGARCH(1,1)

    GJR-GARCH model reviewed #

    A threshold GARCH variant of Glosten, Jagannathan and Runkle (1993) in which squared innovations enter the variance equation with an extra coefficient when the previous innovation was negative, allowing bad news to raise volatility more than good news while remaining in the standard GARCH estimation framework.
    Intuition: It is the GARCH recursion with a switch: yesterday's loss flips on an extra volatility boost that an equal-sized gain does not trigger.
    Mechanics: GJR-GARCH(1,1,1) sets sigma_t^2 = omega + alpha epsilon_{t-1}^2 + gamma epsilon_{t-1}^2 I(epsilon_{t-1} < 0) + beta sigma_{t-1}^2, estimated by maximum likelihood; gamma > 0 measures the leverage effect and the news-impact curve is kinked at zero. Covariance stationarity requires alpha + beta + gamma/2 < 1.
    Failure modes: The 0/1 indicator is a crude step that can misstate the smoothness of the true news-impact curve, and gamma is noisy in calm samples with few large negative shocks. Like other GARCH variants, it is sensitive to structural breaks.
    Misconceptions: That GJR-GARCH predicts negative returns: the asymmetry is in the variance response to realized shocks, not in the conditional mean.
    Example: On daily S&P 500 returns, estimates typically find gamma significant and positive, so a -2% day raises next-day variance by roughly twice what a +2% day does.
    sigma_t^2 = omega + (alpha + gamma I_{t-1}) epsilon_{t-1}^2 + beta sigma_{t-1}^2, where I_{t-1} = 1 if epsilon_{t-1} < 0 and 0 otherwise; the unconditional variance is omega / (1 - alpha - beta - gamma/2).
    Aliases: GJR-GARCH(1,1,1), threshold GARCH

    Stochastic volatility model reviewed #

    A class of models in which volatility is itself a latent stochastic process evolving with its own innovations, rather than a deterministic function of past observed shocks as in GARCH. In continuous time, Heston (1993) models variance as a mean-reverting square-root process driven by its own Brownian motion, possibly correlated with the price shock.
    Intuition: Volatility is an unobserved state variable that wanders randomly and mean-reverts; you see it only through the size of price moves, so inference filters the hidden volatility out of the return data.
    Mechanics: In the Heston specification, dS_t = mu S_t dt + sqrt(v_t) S_t dW^S_t and dv_t = kappa (theta - v_t) dt + sigma_v sqrt(v_t) dW^v_t with correlation rho between the Brownian motions; rho < 0 generates the leverage effect and the implied-volatility skew. Estimation uses filtering or method-of-moments for discrete SV, or semi-closed-form characteristic functions for option pricing under Heston.
    Failure modes: The latent state makes the likelihood intractable in closed form, so estimation is computationally heavy and mean-reversion and vol-of-vol parameters are weakly identified on short samples. Wrong volatility dynamics misprice options even when returns are fit well.
    Misconceptions: That stochastic volatility and GARCH are interchangeable: GARCH variance is measurable given past data, whereas SV variance has its own shock, an extra source of randomness with different option-pricing implications.
    Example: Heston's semi-closed-form option formula uses the characteristic function of the stock under stochastic variance, reproducing the volatility smile that constant-variance Black-Scholes cannot.
    dv_t = kappa (theta - v_t) dt + sigma_v sqrt(v_t) dW^v_t, corr(dW^S_t, dW^v_t) = rho; kappa is the mean-reversion speed, theta the long-run variance, and sigma_v the vol-of-vol.
    Aliases: SV model, Heston model

    Regime-switching model reviewed #

    A time-series model in which the parameters change according to a latent discrete state that itself follows a Markov chain, so the series alternates between distinct regimes such as low-volatility expansion and high-volatility contraction. Hamilton (1989) introduced the framework for business-cycle dynamics.
    Intuition: The market behaves like two different machines, calm and stormy, and an invisible switch flips between them; at any moment you only have a probability of which machine is running.
    Mechanics: An unobserved state s_t in {1,...,N} follows a first-order Markov chain with transition probabilities p_ij, and conditional on s_t the observation follows a regime-specific process (e.g., different means and variances). The Hamilton filter computes filtered regime probabilities recursively, parameters are estimated by maximum likelihood, and smoothed probabilities give retrospective regime dating.
    Failure modes: Regimes are unidentified unless the sample contains enough transitions, and the likelihood is multimodal with label-switching issues. The model assumes abrupt switches, so slowly evolving parameters are forced into spurious extra regimes or poor fits.
    Misconceptions: That filtered regime probabilities are certain knowledge of the current state: they are model-conditional probabilities, and small misspecifications can flip the inferred regime.
    Example: Hamilton modeled U.S. GNP growth with two regimes, positive-growth expansion and negative-growth contraction, whose filtered probabilities closely track NBER recession dates.
    y_t | s_t ~ f(y_t; theta_{s_t}) with P(s_t = j | s_{t-1} = i) = p_ij; e.g., y_t = mu_{s_t} + phi (y_{t-1} - mu_{s_{t-1}}) + sigma_{s_t} epsilon_t.
    Aliases: Markov-switching model, Markov regime-switching
    Related:

    Hidden Markov model reviewed #

    A probabilistic model in which an unobserved finite-state Markov chain generates observable emissions whose distribution depends on the current hidden state, specified by initial-state, transition, and emission probabilities. Rabiner's (1989) tutorial standardized its three canonical problems: evaluation, decoding, and learning.
    Intuition: You cannot see the weather directly, only whether people carry umbrellas; from the umbrella sequence you infer the hidden rainy-or-sunny sequence, given how states persist and how each state produces observations.
    Mechanics: The forward-backward algorithm computes the likelihood of an observation sequence and posterior state probabilities; the Viterbi algorithm decodes the most likely hidden state path; Baum-Welch (EM) re-estimates transition and emission parameters. In financial time series the emissions are typically Gaussian or Student-t densities on returns.
    Failure modes: EM converges to local optima, so results depend on initialization, and the number of states must be chosen heuristically. The geometric state-duration distribution implied by a first-order chain may not match real regime persistence.
    Misconceptions: That the Viterbi path equals the sequence of individually most probable states: they can differ, because Viterbi maximizes the joint probability of the whole path.
    Example: A two-state Gaussian HMM on daily returns separates a low-volatility drift state from a high-volatility drawdown state, and Viterbi decoding yields a hidden regime timeline used as a trend filter.
    lambda = (A, B, pi): A = [a_ij] with a_ij = P(s_{t+1} = j | s_t = i); B = [b_j(o)] with b_j(o) = P(o_t = o | s_t = j); pi_j = P(s_1 = j).
    Aliases: HMM
    Related:

    Kalman filter reviewed #

    A recursive algorithm for optimal linear estimation of the hidden state of a linear Gaussian state-space system, alternating prediction and update steps that weight new observations by their information content. Kalman (1960) derived it as the solution to the linear filtering and prediction problem.
    Intuition: Keep a running best guess of an unobservable quantity plus your uncertainty about it; each new noisy observation nudges the guess toward the data, by more when the data are precise relative to your uncertainty.
    Mechanics: The prediction step projects the state mean and covariance forward through the transition equation; the update step computes the Kalman gain K_t = P_{t|t-1} H' (H P_{t|t-1} H' + R)^{-1} and revises the state using the innovation y_t - H x_{t|t-1}. For linear Gaussian systems the filter is the exact minimum mean-square-error estimator; extended, unscented, and particle variants handle nonlinearity.
    Failure modes: Exact optimality holds only for linear Gaussian systems; with heavy-tailed noise the filter is merely the best linear estimator and is badly distorted by outliers. Misspecified process and observation noise covariances (Q and R) degrade or destabilize estimates.
    Misconceptions: That the Kalman filter is a smoother: it is a causal online filter using only past and current data, while retrospective refinement requires the separate Rauch-Tung-Striebel smoother.
    Example: In pairs trading the hedge ratio is modeled as a random-walk state observed through the spread, and the Kalman filter updates the ratio online as the relationship drifts.
    State: x_t = F x_{t-1} + w_t, w_t ~ N(0,Q); observation: y_t = H x_t + v_t, v_t ~ N(0,R); update: x_{t|t} = x_{t|t-1} + K_t (y_t - H x_{t|t-1}).
    Aliases: Kalman-Bucy filter, linear quadratic estimator

    State-space model reviewed #

    A general time-series framework that represents observed data as noisy measurements of an unobserved state vector evolving through a transition (system) equation, separating the dynamics of the hidden process from measurement error. It subsumes ARMA models, structural time-series models, and time-varying-parameter regressions, and is estimated via the Kalman filter and maximum likelihood.
    Intuition: Split the world into what you cannot see (the true underlying state: trend, seasonal level, drifting coefficient) and what you measure (noisy data), then let filtering theory reconstruct the hidden part.
    Mechanics: A linear Gaussian state-space model pairs a transition equation x_t = F x_{t-1} + w_t with a measurement equation y_t = H x_t + v_t; ARMA, local-level, and local-linear-trend models are special cases with particular F and H. The Kalman filter produces one-step-ahead prediction errors whose Gaussian likelihood is maximized over the hyperparameters, and smoothing recovers the full state history.
    Failure modes: Noise-variance hyperparameters are often weakly identified, so different state decompositions fit equally well with different interpretations. Non-Gaussian or nonlinear models require approximate filters whose accuracy is hard to guarantee.
    Misconceptions: That a state-space model is one specific model: it is a representation framework, and the empirical content comes entirely from the chosen state dynamics and measurement structure.
    Example: A local-level model treats log price as a random-walk level plus observation noise; the Kalman filter estimates the level online, equivalent to an exponentially weighted average with data-driven smoothing.
    x_t = F_t x_{t-1} + w_t, w_t ~ (0, Q_t); y_t = H_t x_t + v_t, v_t ~ (0, R_t).
    Aliases: dynamic linear model, structural time-series model

    Ordinary least squares reviewed #

    The estimation method that chooses regression coefficients to minimize the sum of squared residuals between observed and fitted values, yielding the closed-form estimator beta_hat = (X'X)^{-1} X'y for the linear model. Under the Gauss-Markov assumptions it is the best linear unbiased estimator.
    Intuition: Draw the line (or hyperplane) that makes the total of the squared vertical gaps between data and fit as small as possible; squaring punishes big misses and keeps the algebra tractable.
    Mechanics: Minimizing ||y - X beta||^2 gives the normal equations X'X beta = X'y, solved as beta_hat = (X'X)^{-1} X'y when X has full column rank. Inference uses the residual variance s^2 = e'e/(n-k) and Var(beta_hat) = s^2 (X'X)^{-1}, with exact t- and F-tests under normal errors.
    Failure modes: OLS is highly sensitive to outliers and high-leverage points, breaks down when X'X is near-singular from multicollinearity, and its standard errors are invalid under heteroskedasticity or autocorrelated errors. On unit-root data it produces spurious regressions.
    Misconceptions: That minimizing squared error makes OLS optimal in general: its BLUE property requires exogeneity, linearity, and spherical errors, and outside those it can be dominated by GLS, ridge, or robust estimators.
    Example: Regressing a stock's daily returns on the market's returns by OLS gives the slope minimizing squared return gaps, the standard CAPM beta estimate.
    beta_hat = argmin_b sum_i (y_i - x_i' b)^2 = (X'X)^{-1} X'y, where X is the n x k design matrix and y the response vector.
    Aliases: OLS, least squares

    Linear regression reviewed #

    A statistical model relating a response variable to one or more explanatory variables through a function linear in the unknown parameters, y_i = beta_0 + beta_1 x_i + ... + epsilon_i, typically estimated by least squares. 'Linear' refers to linearity in the parameters, so transformed or polynomial terms in the variables are permitted.
    Intuition: Summarize how y moves with x by a straight-line relationship plus noise: each coefficient reads as the expected change in y per unit change in its x, holding the others fixed.
    Mechanics: Specify the functional form, estimate coefficients (usually OLS), then validate: residual plots for functional form and constant variance, t-tests for individual coefficients, an F-test for overall fit, and R-squared for the share of variance explained. Predictions are x'beta_hat with intervals derived from the estimated covariance matrix.
    Failure modes: Misspecified functional form or omitted variables bias all coefficients, and influential outliers can dominate the fit. In time series, autocorrelated errors and trending data invalidate standard inference, up to spurious regression with unit roots.
    Misconceptions: That a significant regression implies causation: regression measures conditional association, and a causal reading requires exogeneity, which is an assumption rather than a result of the fit.
    Example: Regressing changes in 10-year yields on changes in the policy rate gives a slope near 0.4: on average a one-point policy move transmits as 0.4 points to long yields in the sample.
    y_i = beta_0 + beta_1 x_{i1} + ... + beta_k x_{ik} + epsilon_i, with E[epsilon_i | X] = 0, estimated by minimizing the sum of squared residuals.
    Aliases: least-squares regression, simple linear regression

    Multiple regression reviewed #

    Linear regression with two or more explanatory variables, y = X beta + epsilon, in which each coefficient measures the partial association between the response and one regressor holding the others constant. It is estimated by OLS as beta_hat = (X'X)^{-1} X'y.
    Intuition: With several predictors at once, each coefficient answers: what does this variable add given everything else already in the model? That is why coefficients can change sign when a correlated variable is added.
    Mechanics: Coefficients are estimated jointly by least squares and interpreted ceteris paribus. Overall fit is judged by R-squared and the F-test, individual contributions by t-tests or partial F-tests, and specification by residual analysis, adjusted R-squared, and information criteria.
    Failure modes: Multicollinearity inflates coefficient variances, making estimates unstable and sign-fragile, and adding irrelevant variables inflates in-sample R-squared without improving prediction (overfitting).
    Misconceptions: That each coefficient shows the total effect of its variable: it is a partial effect conditional on the other regressors, and it changes when the regressor set changes.
    Example: Modeling next-quarter earnings from revenue growth, margin, and a sector dummy: the revenue-growth coefficient measures its association with earnings after removing margin and sector effects.
    y_i = beta_0 + beta_1 x_{i1} + ... + beta_k x_{ik} + epsilon_i; beta_hat = (X'X)^{-1} X'y with Var(beta_hat) = sigma^2 (X'X)^{-1}.
    Aliases: multiple linear regression, multivariable regression

    Logistic regression reviewed #

    A regression model for a binary outcome that models the log-odds of the event as a linear function of the predictors, so predicted probabilities stay bounded between 0 and 1. Developed in its modern form by Cox (1958) and estimated by maximum likelihood rather than least squares.
    Intuition: Instead of predicting the 0/1 outcome directly, predict the odds of the event on a log scale, where a straight line makes sense, then squash the result back to a probability with the logistic curve.
    Mechanics: logit P(y=1|x) = beta_0 + x'beta, fitted by maximizing the Bernoulli log-likelihood; exponentiated coefficients give odds ratios per unit change in a predictor. Inference uses Wald, likelihood-ratio, or score tests, and fit is assessed with deviance and pseudo-R-squared measures.
    Failure modes: Complete or quasi-complete separation (a predictor perfectly splits the outcomes) makes the MLEs diverge, and rare events bias small-sample estimates. The linear-in-log-odds form misses interactions and nonlinearities unless they are added explicitly.
    Misconceptions: That the coefficients are marginal effects on probability: they are effects on log-odds, and the probability effect varies with x, equal to beta_j p(1-p).
    Example: Modeling whether a stock beats the index next month (1/0) from momentum and valuation z-scores: exp(beta) for momentum is the multiplicative change in the odds of outperformance per z-score unit.
    P(y=1|x) = 1 / (1 + exp(-(beta_0 + beta_1 x_1 + ... + beta_k x_k))); the log-odds log(p/(1-p)) = beta_0 + x'beta.
    Aliases: logit model, binary logistic model

    Ridge regression reviewed #

    A regularized least-squares estimator that shrinks coefficients toward zero by adding a penalty proportional to the sum of squared coefficients, trading a small bias for a large variance reduction when predictors are collinear. Introduced by Hoerl and Kennard (1970) for nonorthogonal problems.
    Intuition: When predictors are highly correlated, OLS coefficients swing wildly between samples; ridge charges a price for large coefficients, keeping them small and stable at the cost of a slight pull toward zero.
    Mechanics: beta_hat = (X'X + lambda I)^{-1} X'y minimizes ||y - X beta||^2 + lambda ||beta||^2, with lambda >= 0 chosen by cross-validation and predictors standardized so the penalty treats them comparably. Ridge never sets coefficients exactly to zero: it shrinks all of them.
    Failure modes: The choice of lambda is critical and data-driven, and too much shrinkage underfits. Ridge keeps every variable in the model, so it does no variable selection when the truth is sparse.
    Misconceptions: That ridge coefficients are unbiased shrunken versions of OLS: they are deliberately biased, and the method wins on mean-squared error, not unbiasedness.
    Example: Predicting sector returns from 50 correlated macro factors: OLS loadings are unstable across samples, while ridge with cross-validated lambda gives stable loadings and better out-of-sample fit.
    beta_hat = argmin_b { sum_i (y_i - x_i' b)^2 + lambda sum_j b_j^2 } = (X'X + lambda I)^{-1} X'y.
    Aliases: Tikhonov regularization, L2-regularized regression

    Lasso regression reviewed #

    Least absolute shrinkage and selection operator: a regularized regression that penalizes the sum of absolute coefficient values, which both shrinks coefficients and sets some exactly to zero, performing continuous variable selection. Introduced by Tibshirani (1996).
    Intuition: The L1 penalty has corners at zero, so as the penalty tightens the least useful coefficients are pushed exactly to zero and drop out: shrinkage and feature selection in one step.
    Mechanics: beta_hat minimizes (1/2n) ||y - X beta||^2 + lambda ||beta||_1; there is no closed form, so the path is computed by coordinate descent or LARS with lambda chosen by cross-validation on standardized predictors. The selected model is often refit by OLS (relaxed lasso) to reduce shrinkage bias on the retained coefficients.
    Failure modes: With highly correlated predictors the lasso selects arbitrarily among them, making the selected set unstable across samples, and when p > n it can select at most n variables. Its aggressive selection can drop weak but real predictors.
    Misconceptions: That lasso selection leaves usual inference intact: p-values computed after data-driven selection are invalid without selective-inference corrections.
    Example: Screening 200 candidate anomaly signals for return prediction, the lasso path zeroes out all but about 15 signals as lambda decreases, isolating a sparse predictor set.
    beta_hat = argmin_b { (1/2n) sum_i (y_i - x_i' b)^2 + lambda sum_j |b_j| }.
    Aliases: lasso, L1 regularization
    Related:
    • Ridge regression

    Elastic net reviewed #

    A regularized regression combining the L1 (lasso) and L2 (ridge) penalties, retaining the lasso's variable selection while adding a grouping effect that keeps strongly correlated predictors in or out of the model together. Introduced by Zou and Hastie (2005).
    Intuition: Pure lasso tends to pick one variable out of a correlated cluster and drop the rest; mixing in ridge penalty makes the whole cluster share the coefficient, which is stabler when predictors travel in packs.
    Mechanics: beta_hat minimizes (1/2n) ||y - X beta||^2 + lambda [alpha ||beta||_1 + (1-alpha) ||beta||^2 / 2], with alpha mixing lasso (alpha=1) and ridge (alpha=0); both hyperparameters are chosen by cross-validation and the fit is computed by coordinate descent. It is especially useful when p >> n, where lasso saturates at n selected variables.
    Failure modes: Two tuning parameters make selection costlier and more prone to validation overfitting, and as with lasso, naive post-selection inference is invalid.
    Misconceptions: That elastic net always dominates lasso: with truly sparse, weakly correlated predictors plain lasso is simpler and comparably good; elastic net's advantage concentrates in grouped, collinear designs.
    Example: Selecting among hundreds of correlated technical indicators, elastic net keeps whole families of similar momentum variants together instead of arbitrarily discarding all but one.
    beta_hat = argmin_b { (1/2n) ||y - Xb||^2 + lambda ( alpha ||b||_1 + (1 - alpha) ||b||^2 / 2 ) }.
    Aliases: elastic net regularization, L1/L2 penalty

    Residual reviewed #

    The difference between an observed response and the value fitted by a model, e_i = y_i - f(x_i; beta_hat). Residuals are the observable proxies for the unobservable error terms and the primary diagnostic for model adequacy.
    Intuition: The leftover after the model has said its piece: if the model captured the structure, the leftovers should look like pure noise with nothing left to exploit.
    Mechanics: Residuals are computed from the fitted model and examined graphically (against fitted values, regressors, and time order) for nonlinearity, non-constant variance, drift, autocorrelation, and non-normality; formal tests such as Breusch-Pagan or Ljung-Box complement the plots. Standardized and studentized versions flag outliers.
    Failure modes: Structured residuals signal misspecification, but pattern-free residuals do not prove the model is right: they cannot reveal omitted variables uncorrelated with the included ones. In time series, ignored residual autocorrelation invalidates standard errors.
    Misconceptions: That residuals are the same as the true errors: residuals are estimates constrained by the fit (they sum to zero and are mutually correlated), so their distribution only approximates that of the errors.
    Example: After fitting an AR(1) to returns, the Ljung-Box test on squared residuals still shows correlation, meaning the variance structure remains unmodeled and motivating a GARCH extension.
    e_i = y_i - f(x_i; beta_hat); in OLS with an intercept the residuals satisfy sum e_i = 0 and X'e = 0.
    Aliases: regression residual, fitted error

    R-squared reviewed #

    The coefficient of determination: the proportion of the total sample variation in the response accounted for by the regression model, computed as one minus the ratio of the residual to the total sum of squares. For OLS with an intercept it equals the squared correlation between observed and fitted values.
    Intuition: A 0-to-1 score of how much of the ups and downs in y the model reproduces: R^2 = 0.7 means 70% of the variance is captured by the regressors and 30% is left in the noise.
    Mechanics: R^2 = 1 - SS_res/SS_tot with SS_res = sum e_i^2 and SS_tot = sum (y_i - y_bar)^2. Because adding regressors never decreases in-sample R^2, it cannot compare models with different parameter counts; adjusted R^2 or out-of-sample criteria serve that role, and without an intercept or out of sample R^2 can be negative.
    Failure modes: A high R^2 does not imply the model is correct, causal, or predictive out of sample; with trending time series, spurious regressions routinely show R^2 above 0.9.
    Misconceptions: That R^2 measures predictive accuracy: it measures in-sample fit, and out-of-sample R^2 can be negative even when in-sample R^2 is high.
    Example: A regression of a fund's monthly returns on the market factor gives R^2 = 0.85, meaning 85% of the fund's return variance co-moved with the market in the sample.
    R^2 = 1 - SS_res / SS_tot = 1 - sum (y_i - y_hat_i)^2 / sum (y_i - y_bar)^2.
    Aliases: coefficient of determination, R^2

    Adjusted R-squared reviewed #

    A degrees-of-freedom-corrected version of R^2 that penalizes model complexity, so it increases only when a new regressor improves fit more than would be expected by chance. The standard correction is due to Ezekiel.
    Intuition: R^2 always rises when you add variables, even junk ones; adjusted R^2 charges a complexity tax per parameter so it only rises if the new variable genuinely earns its place.
    Mechanics: R-bar^2 = 1 - (1 - R^2)(n - 1)/(n - k - 1), replacing raw sums of squares by mean squares. It can decline when weak regressors are added and can be negative, and it is commonly used to compare nested candidate models with different k.
    Failure modes: It remains an in-sample criterion and does not protect against overfitting the way cross-validation does, and it is not an unbiased estimator of the population R^2 (the Olkin-Pratt estimator improves on it).
    Misconceptions: That adjusted R^2 solves model selection: it is a rough penalty that ignores parameter uncertainty and out-of-sample performance.
    Example: Adding a fifth factor to a return regression raises R^2 from 0.42 to 0.43 but lowers adjusted R^2 from 0.405 to 0.402, suggesting the new factor adds noise rather than signal.
    R-bar^2 = 1 - (1 - R^2)(n - 1)/(n - k - 1), where n is the sample size and k the number of regressors excluding the intercept.
    Aliases: adjusted R^2, R-bar-squared

    Multicollinearity reviewed #

    A condition in regression in which two or more explanatory variables are highly linearly related, so the design matrix is nearly rank-deficient and individual coefficients cannot be estimated precisely, although the model as a whole may still predict well.
    Intuition: If two predictors move together, the data cannot tell which one deserves the credit: many different coefficient splits fit almost equally well, so each estimate has a huge standard error and can flip sign between samples.
    Mechanics: Diagnosed by high pairwise correlations, variance inflation factors VIF_j = 1/(1 - R_j^2) from regressing each predictor on the others, and the condition number of X'X. Remedies include dropping or combining variables, principal components, ridge regression, or accepting imprecise individual coefficients when only prediction matters.
    Failure modes: Perfect collinearity makes OLS non-unique (X'X singular), and near-collinearity inflates Var(beta_j) by the VIF and makes estimates hypersensitive to tiny data changes. It also undermines causal attribution within the collinear set.
    Misconceptions: That multicollinearity biases OLS or ruins prediction: estimates remain unbiased and fitted values are stable; only the precision and interpretability of individual coefficients suffer.
    Example: Regressing house prices on both living area and room count, correlated at 0.9: both VIFs exceed 8 and neither coefficient is significant even though the joint F-test is highly significant.
    VIF_j = 1 / (1 - R_j^2), where R_j^2 is the R-squared from regressing predictor j on the other predictors; values above about 10 are commonly taken to indicate serious collinearity.
    Aliases: collinearity, ill-conditioned design matrix

    Endogeneity reviewed #

    The failure of the exogeneity condition E[epsilon | X] = 0 in a regression, i.e., a regressor correlated with the error term, arising from omitted variables, simultaneity (reverse causation), or measurement error. It renders OLS estimates biased and inconsistent.
    Intuition: The regressor and the leftover noise are tangled together, so the coefficient absorbs part of the noise's influence and no longer isolates the variable's own effect.
    Mechanics: Sources include omitted variables correlated with included regressors, simultaneous determination of y and x, and errors-in-variables (attenuation bias). Diagnosis uses Durbin-Wu-Hausman tests comparing OLS to IV estimates; remedies include instrumental variables, natural experiments, fixed effects, or control functions.
    Failure modes: Endogeneity cannot be detected from the regression output alone: it is a property of the data-generating process, so asserting exogeneity requires external argument. IV fixes are only as good as the instruments.
    Misconceptions: That adding more controls always reduces endogeneity: controlling for variables that are themselves outcomes of x or of the error (bad controls, colliders) can create bias rather than remove it.
    Example: Regressing asset returns on fund flows is contaminated because flows respond to past and anticipated returns, so flow is endogenous and the price-impact coefficient mixes in reverse causality.
    In y = beta x + epsilon, endogeneity means Cov(x, epsilon) != 0, so plim beta_hat_OLS = beta + Cov(x, epsilon)/Var(x) != beta.
    Aliases: regressor-error correlation, simultaneity bias

    Instrumental variable reviewed #

    A variable used to identify a causal effect when the regressor of interest is endogenous: a valid instrument is correlated with the endogenous regressor (relevance) and affects the outcome only through that regressor (exclusion restriction), isolating an exogenous source of variation.
    Intuition: Find a lever that shifts the troublesome variable for reasons unrelated to everything else in the error term, then measure how the outcome responds to those lever-induced shifts only.
    Mechanics: In two-stage least squares the endogenous x is regressed on the instrument z (first stage) and y on the fitted x (second stage); the just-identified IV estimand is Cov(y,z)/Cov(x,z), interpretable under monotonicity as a local average treatment effect (Angrist, Imbens and Rubin 1996). First-stage F-statistics check relevance; overidentification tests partially probe exclusion.
    Failure modes: Weak instruments (low first-stage F) leave the estimator biased toward OLS with non-normal finite-sample distributions, and the exclusion restriction is untestable in the just-identified case, so invalid instruments deliver consistent estimates of the wrong quantity.
    Misconceptions: That any variable correlated with x works as an instrument: without a defensible exclusion restriction the estimate is meaningless, and the estimand is local (LATE), not a universal average effect.
    Example: Angrist used the Vietnam-era draft lottery as an instrument for military service: lottery numbers shifted service probability essentially randomly, identifying the causal effect of service on later earnings.
    beta_IV = (Z'X)^{-1} Z'y; in the single-instrument, single-regressor case, beta_IV = Cov(z, y) / Cov(z, x).
    Aliases: IV, instrument, two-stage least squares (2SLS)

    Maximum likelihood estimation reviewed #

    A general estimation principle that chooses parameter values maximizing the likelihood, the probability (density) of the observed data viewed as a function of the parameters, so the fitted model makes the observed sample as probable as possible. Fisher (1922) founded the method and established its consistency, efficiency, and asymptotic normality.
    Intuition: Treat the data as fixed and ask which parameter values would have made this exact dataset most likely to occur; those are the estimates.
    Mechanics: Form L(beta) = prod f(y_i; beta), or the log-likelihood l = sum log f, maximize it analytically or numerically, and take standard errors from the inverse observed information (negative Hessian). Under regularity conditions MLEs are consistent, asymptotically efficient, and asymptotically normal, enabling Wald, likelihood-ratio, and score tests.
    Failure modes: The good properties are asymptotic: small-sample MLEs can be biased (e.g., variance parameters), and everything rests on correct specification, with quasi-MLE corrections needed when the density is wrong. Numerical maximization can hit local optima or diverge, as with separation in logit models.
    Misconceptions: That MLE finds the most probable parameter value: it maximizes the probability of the data given the parameter, not the probability of the parameter, which requires a prior (Bayesian inference).
    Example: Fitting GARCH(1,1) to returns maximizes the product of conditional normal densities N(0, sigma_t^2) over (omega, alpha, beta), with standard errors from the Hessian of the log-likelihood.
    beta_hat_MLE = argmax_beta sum_i log f(y_i; beta); asymptotically beta_hat ~ N(beta, I(beta)^{-1}), with I the Fisher information.
    Aliases: MLE, maximum likelihood

    Bayesian inference reviewed #

    A framework for statistical inference in which unknown parameters are treated as random variables with prior distributions that are updated to posterior distributions via Bayes's theorem as data arrive, so all conclusions are probability statements about parameters given the data.
    Intuition: Start with a belief, weigh it against the evidence the data carry, and come out with an updated belief: inference is the continuous revision of probabilities.
    Mechanics: The posterior is proportional to likelihood times prior, p(theta|y) proportional to f(y|theta) p(theta). Point summaries (posterior mean or mode), credible intervals, and posterior predictive checks replace classical estimates and p-values, with computation by conjugate updating, grid methods, or MCMC when no closed form exists.
    Failure modes: Results depend on the prior, especially with small samples or weakly identified parameters, where a poor prior can dominate the data. Posterior computation can be intractable and MCMC convergence is not guaranteed.
    Misconceptions: That Bayesian and frequentist intervals mean the same thing: a 95% credible interval contains the parameter with 95% posterior probability, whereas a 95% confidence interval covers the truth in 95% of repeated samples.
    Example: Updating a belief about a coin's bias from a Beta(2,2) prior after 8 heads in 10 flips gives a Beta(10,4) posterior, shifting probability mass toward high bias values.
    p(theta | y) = f(y | theta) p(theta) / p(y), i.e., posterior proportional to likelihood x prior, with p(y) = integral f(y|theta) p(theta) dtheta the normalizing evidence.
    Aliases: Bayesian updating, Bayesian statistics

    Posterior distribution reviewed #

    The probability distribution of unknown parameters after conditioning on the observed data, obtained by Bayes's theorem as the normalized product of the likelihood and the prior. It is the central output of Bayesian inference.
    Intuition: Your belief about the parameter after seeing the evidence, expressed as a full distribution rather than a single number, so it gives both a best guess and the remaining uncertainty.
    Mechanics: p(theta|y) is proportional to f(y|theta) p(theta); with conjugate priors the posterior stays in the same family (Beta-Binomial, Normal-Normal) and updates analytically, otherwise it is approximated by MCMC or variational methods. Posterior means, medians, and credible intervals summarize it, and the posterior predictive propagates parameter uncertainty into forecasts.
    Failure modes: The posterior inherits prior influence and model misspecification: with a wrong likelihood family it concentrates confidently on the wrong value as n grows. Multimodal or high-dimensional posteriors are hard to sample and summarize.
    Misconceptions: That the posterior describes the sampling variability of an estimator: it is a direct probability statement about the parameter itself given this dataset.
    Example: For a Normal mean with a Normal prior, the posterior mean is a precision-weighted average of the sample mean and the prior mean, with the data dominating as n grows.
    p(theta | y) = f(y | theta) p(theta) / integral f(y | theta') p(theta') dtheta'.
    Aliases: posterior, posterior density

    Prior distribution reviewed #

    The probability distribution assigned to unknown parameters before observing the data, encoding pre-existing knowledge or deliberately weak information; it combines with the likelihood through Bayes's theorem to form the posterior.
    Intuition: What you believe before the experiment: it can be an informed guess from past data or a deliberately vague statement, but it must be written down so its influence on the answer is visible.
    Mechanics: Priors range from informative (elicited from domain knowledge) through weakly informative to reference forms (uniform, Jeffreys). Conjugate priors keep the posterior in the same family for computational convenience, and sensitivity analysis reruns the analysis across priors to measure their influence.
    Failure modes: An overconfident informative prior can swamp the data and dictate conclusions, and ostensibly flat priors are not invariant to reparameterization and can be improper, risking improper posteriors.
    Misconceptions: That a prior makes inference purely arbitrary: priors make assumptions explicit and checkable, and with enough data reasonable priors lead to similar posteriors (likelihood dominance).
    Example: A trader puts a Normal(0, 1%) prior on a strategy's true daily alpha before seeing backtest results, so the posterior shrinks extreme backtest alphas toward zero.
    p(theta); the posterior is proportional to likelihood times prior: p(theta|y) proportional to f(y|theta) p(theta).
    Aliases: prior, a priori distribution

    Likelihood function reviewed #

    The joint probability (density) of the observed data expressed as a function of the model parameters with the data held fixed, L(theta) = f(y_1,...,y_n; theta). It measures the relative plausibility of parameter values and is the object maximized in maximum likelihood estimation, introduced by Fisher (1922).
    Intuition: The same formula as the probability of the data, read backwards: instead of asking what data these parameters might produce, ask how probable this dataset is under each candidate parameter.
    Mechanics: For i.i.d. data L(theta) = prod f(y_i; theta), and the log-likelihood l(theta) = sum log f(y_i; theta) is used for numerical stability. The score (gradient of l) and the Fisher information (expected negative curvature) drive estimation and inference, and likelihood ratios compare nested models.
    Failure modes: The likelihood is only as meaningful as the assumed data-generating density; misspecification yields confident but wrong inference. Flat or ridged likelihoods indicate weak identification, and the likelihood alone carries no prior weighting.
    Misconceptions: That the likelihood is a probability distribution over parameters: it is not normalized in theta and cannot be integrated as a probability without a prior.
    Example: For ten independent Bernoulli trials with 7 successes, L(p) = p^7 (1-p)^3 is maximized at p = 0.7, so values near 0.7 are more likely explanations of the data than p = 0.5.
    L(theta) = prod_{i=1}^n f(y_i; theta); l(theta) = sum_i log f(y_i; theta); the likelihood ratio for two values is L(theta_1)/L(theta_2).
    Aliases: likelihood, log-likelihood
