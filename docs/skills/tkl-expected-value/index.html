    Concept evidence

    The probability-weighted average of all possible values of a random variable; the long-run mean outcome if the experiment is repeated indefinitely. It is the first moment of a probability distribution.

    Intuition

    It is the average you would converge to after many repetitions, not necessarily a value that can actually occur. A bet has positive expected value if the probability-weighted payouts exceed the stake over the long run.

    Mechanics

    For a discrete random variable, multiply each possible value by its probability and sum the products; for a continuous variable, integrate x times the density. Linearity of expectation (E[aX + bY] = aE[X] + bE[Y]) holds even when variables are dependent.

    Formula
    Discrete: E[X] = SUM x_i * P(x_i). Continuous: E[X] = integral of x * f(x) dx over the support, where f is the probability density function.

    Failure modes

    The expected value need not exist for heavy-tailed distributions (the Cauchy distribution has no mean), and it can be a misleading summary of a single risky decision when the distribution is skewed or the stakes are ruinous. Expectation ignores variance and path, so equal-mean bets can have wildly different risk.

    Misconceptions

    The expected value is not the most likely outcome (that is the mode) and need not be a possible value at all - a die's expected roll is 3.5. A positive-expectancy strategy can still lose over any finite horizon.

    Example

    A trade wins 10% with probability 0.55 and loses 8% with probability 0.45; E[return] = 0.55*0.10 + 0.45*(-0.08) = 0.019, or 1.9% per trade on average.
