Kalman filter

DomainTime-series analysis

Trading concept

A recursive algorithm for optimal linear estimation of the hidden state of a linear Gaussian state-space system, alternating prediction and update steps that weight new observations by their information content. Kalman (1960) derived it as the solution to the linear filtering and prediction problem.

Intuition

Keep a running best guess of an unobservable quantity plus your uncertainty about it; each new noisy observation nudges the guess toward the data, by more when the data are precise relative to your uncertainty.

Mechanics

The prediction step projects the state mean and covariance forward through the transition equation; the update step computes the Kalman gain K_t = P_{t|t-1} H' (H P_{t|t-1} H' + R)^{-1} and revises the state using the innovation y_t - H x_{t|t-1}. For linear Gaussian systems the filter is the exact minimum mean-square-error estimator; extended, unscented, and particle variants handle nonlinearity.

Formula
State: x_t = F x_{t-1} + w_t, w_t ~ N(0,Q); observation: y_t = H x_t + v_t, v_t ~ N(0,R); update: x_{t|t} = x_{t|t-1} + K_t (y_t - H x_{t|t-1}).

Failure modes

Exact optimality holds only for linear Gaussian systems; with heavy-tailed noise the filter is merely the best linear estimator and is badly distorted by outliers. Misspecified process and observation noise covariances (Q and R) degrade or destabilize estimates.

Misconceptions

That the Kalman filter is a smoother: it is a causal online filter using only past and current data, while retrospective refinement requires the separate Rauch-Tung-Striebel smoother.

Example

In pairs trading the hedge ratio is modeled as a random-walk state observed through the spread, and the Kalman filter updates the ratio online as the relationship drifts.
