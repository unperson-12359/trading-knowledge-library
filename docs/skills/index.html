    Architecture

    One repository router handles discovery; focused, self-contained concept packages remain organized in the GitHub catalog so a host does not need to load 1,500 skill descriptions into every context.

    • Skills package reusable workflows; the existing concept JSON remains the factual source of truth.
    • A 1,500-skill discovery list can exceed the host metadata budget and cause descriptions or skills to be omitted.
    • A router preserves reliable discovery while individual catalog packages remain portable and directly readable from GitHub.
    • Generated concept references carry canonical hashes so duplicated package data cannot silently drift.
