    2-period simple return #

    The simple (holding-period) return of an asset between the current observation and the observation 2 periods earlier, expressed as the fractional change in price over that span. It is the standard discrete, non-compounded return measure applied to a 2-period lookback on any bar frequency (minutes, days, weeks, etc.).
    Open unified concept + skill view →
    Intuition: It answers: 'how much did the price move, in percentage terms, over the last 2 bars?' A 2-period simple return of 0.05 means the price is 5% higher than it was 2 periods ago.
    Mechanics: Divide the current closing price by the closing price 2 periods earlier and subtract 1; the result is a fraction (multiply by 100 for a percentage). Standard implementation convention: pandas Series.pct_change(periods=2), which leaves the first 2 values undefined (NaN) because 2 prior observations are required; the span covers 2 sampling intervals and therefore uses 3 prices. Use split- and dividend-adjusted prices for a total-return measure; raw closes yield a price return only.
    Failure modes: The measure depends only on the two endpoint prices, so a single outlier, stale quote, or illiquid print at either end distorts it, and it ignores the path taken in between. Overlapping 2-period windows also induce strong serial correlation in the resulting series, which invalidates naive statistical tests.
    Misconceptions: A 2-period simple return is not 2 times the average one-period return (multi-period gains compound: R = product of (1 + r_i) - 1), and a +x% move is not cancelled by a later -x% move. It also excludes dividends unless adjusted prices are used, so it understates the total return of income-paying assets.
    Example: On daily bars, a stock closed at $42.00 2 trading days ago and closes at $43.26 today; the 2-period simple return is 43.26/42.00 - 1 = +3.00%.
    R_t(2) = P_t / P_(t-2) - 1 = (P_t - P_(t-2)) / P_(t-2), where P_t is the (adjusted) closing price at observation t and 2 is the lookback in periods. Multiply by 100 to express the result as a percentage.
    Aliases: 2-period return, 2-period holding period return, 2-period price return
    Related:

    • Holding period return
    • Log return
    • Rate of change (ROC)
    • Momentum
    • Total return

    The simple (holding-period) return of an asset between the current observation and the observation 12 periods earlier, expressed as the fractional change in price over that span. It is the standard discrete, non-compounded return measure applied to a 12-period lookback on any bar frequency (minutes, days, weeks, etc.).
    Open unified concept + skill view →
    Intuition: It answers: 'how much did the price move, in percentage terms, over the last 12 bars?' A 12-period simple return of 0.05 means the price is 5% higher than it was 12 periods ago.
    Mechanics: Divide the current closing price by the closing price 12 periods earlier and subtract 1; the result is a fraction (multiply by 100 for a percentage). Standard implementation convention: pandas Series.pct_change(periods=12), which leaves the first 12 values undefined (NaN) because 12 prior observations are required; the span covers 12 sampling intervals and therefore uses 13 prices. Use split- and dividend-adjusted prices for a total-return measure; raw closes yield a price return only.
    Failure modes: The measure depends only on the two endpoint prices, so a single outlier, stale quote, or illiquid print at either end distorts it, and it ignores the path taken in between. Overlapping 12-period windows also induce strong serial correlation in the resulting series, which invalidates naive statistical tests.
    Misconceptions: A 12-period simple return is not 12 times the average one-period return (multi-period gains compound: R = product of (1 + r_i) - 1), and a +x% move is not cancelled by a later -x% move. It also excludes dividends unless adjusted prices are used, so it understates the total return of income-paying assets.
    Example: On daily bars, a stock closed at $52.00 12 trading days ago and closes at $53.04 today; the 12-period simple return is 53.04/52.00 - 1 = +2.00%.
    R_t(12) = P_t / P_(t-12) - 1 = (P_t - P_(t-12)) / P_(t-12), where P_t is the (adjusted) closing price at observation t and 12 is the lookback in periods. Multiply by 100 to express the result as a percentage.
    Aliases: 12-period return, 12-period holding period return, 12-period price return

    Intuition: It answers: 'how much did the price move, in percentage terms, over the last 23 bars?' A 23-period simple return of 0.05 means the price is 5% higher than it was 23 periods ago.
    Mechanics: Divide the current closing price by the closing price 23 periods earlier and subtract 1; the result is a fraction (multiply by 100 for a percentage). Standard implementation convention: pandas Series.pct_change(periods=23), which leaves the first 23 values undefined (NaN) because 23 prior observations are required; the span covers 23 sampling intervals and therefore uses 24 prices. Use split- and dividend-adjusted prices for a total-return measure; raw closes yield a price return only.
    Failure modes: The measure depends only on the two endpoint prices, so a single outlier, stale quote, or illiquid print at either end distorts it, and it ignores the path taken in between. Overlapping 23-period windows also induce strong serial correlation in the resulting series, which invalidates naive statistical tests.
    Misconceptions: A 23-period simple return is not 23 times the average one-period return (multi-period gains compound: R = product of (1 + r_i) - 1), and a +x% move is not cancelled by a later -x% move. It also excludes dividends unless adjusted prices are used, so it understates the total return of income-paying assets.
    Example: On daily bars, a stock closed at $63.00 23 trading days ago and closes at $63.76 today; the 23-period simple return is 63.76/63.00 - 1 = +1.21%.
    R_t(23) = P_t / P_(t-23) - 1 = (P_t - P_(t-23)) / P_(t-23), where P_t is the (adjusted) closing price at observation t and 23 is the lookback in periods. Multiply by 100 to express the result as a percentage.
