    27-period simple return #

    The simple (holding-period) return of an asset between the current observation and the observation 27 periods earlier, expressed as the fractional change in price over that span. It is the standard discrete, non-compounded return measure applied to a 27-period lookback on any bar frequency (minutes, days, weeks, etc.).
    Open unified concept + skill view →
    Intuition: It answers: 'how much did the price move, in percentage terms, over the last 27 bars?' A 27-period simple return of 0.05 means the price is 5% higher than it was 27 periods ago.
    Mechanics: Divide the current closing price by the closing price 27 periods earlier and subtract 1; the result is a fraction (multiply by 100 for a percentage). Standard implementation convention: pandas Series.pct_change(periods=27), which leaves the first 27 values undefined (NaN) because 27 prior observations are required; the span covers 27 sampling intervals and therefore uses 28 prices. Use split- and dividend-adjusted prices for a total-return measure; raw closes yield a price return only.
    Failure modes: The measure depends only on the two endpoint prices, so a single outlier, stale quote, or illiquid print at either end distorts it, and it ignores the path taken in between. Overlapping 27-period windows also induce strong serial correlation in the resulting series, which invalidates naive statistical tests.
    Misconceptions: A 27-period simple return is not 27 times the average one-period return (multi-period gains compound: R = product of (1 + r_i) - 1), and a +x% move is not cancelled by a later -x% move. It also excludes dividends unless adjusted prices are used, so it understates the total return of income-paying assets.
    Example: On daily bars, a stock closed at $67.00 27 trading days ago and closes at $66.33 today; the 27-period simple return is 66.33/67.00 - 1 = -1.00%.
    R_t(27) = P_t / P_(t-27) - 1 = (P_t - P_(t-27)) / P_(t-27), where P_t is the (adjusted) closing price at observation t and 27 is the lookback in periods. Multiply by 100 to express the result as a percentage.
    Aliases: 27-period return, 27-period holding period return, 27-period price return
    Related:
    • Simple return
    • Holding period return
    • Log return
    • Rate of change (ROC)
    • Momentum
    • Total return
    Source: Business Finance (Mishra, Deakin University, 2023, CAUL OER Collective) — Topic 2: Risk and Return Part I, Concept 1: Measures of return (holding period return, percentage returns) — Topic 2, pp. 14-16 (holding period return; capital gains yield = (ending price - beginning price)/beginning price)
    Source: pandas.DataFrame.pct_change — pandas 3.0.5 documentation — Parameters: periods (int, default 1) — periods to shift for forming percent change

    49-period simple return #

    The simple (holding-period) return of an asset between the current observation and the observation 49 periods earlier, expressed as the fractional change in price over that span. It is the standard discrete, non-compounded return measure applied to a 49-period lookback on any bar frequency (minutes, days, weeks, etc.).
    Intuition: It answers: 'how much did the price move, in percentage terms, over the last 49 bars?' A 49-period simple return of 0.05 means the price is 5% higher than it was 49 periods ago.
    Mechanics: Divide the current closing price by the closing price 49 periods earlier and subtract 1; the result is a fraction (multiply by 100 for a percentage). Standard implementation convention: pandas Series.pct_change(periods=49), which leaves the first 49 values undefined (NaN) because 49 prior observations are required; the span covers 49 sampling intervals and therefore uses 50 prices. Use split- and dividend-adjusted prices for a total-return measure; raw closes yield a price return only.
    Failure modes: The measure depends only on the two endpoint prices, so a single outlier, stale quote, or illiquid print at either end distorts it, and it ignores the path taken in between. Overlapping 49-period windows also induce strong serial correlation in the resulting series, which invalidates naive statistical tests.
    Misconceptions: A 49-period simple return is not 49 times the average one-period return (multi-period gains compound: R = product of (1 + r_i) - 1), and a +x% move is not cancelled by a later -x% move. It also excludes dividends unless adjusted prices are used, so it understates the total return of income-paying assets.
    Example: On daily bars, a stock closed at $89.00 49 trading days ago and closes at $87.66 today; the 49-period simple return is 87.66/89.00 - 1 = -1.51%.
