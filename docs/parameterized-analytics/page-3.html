    52-period simple return #

    The simple (holding-period) return of an asset between the current observation and the observation 52 periods earlier, expressed as the fractional change in price over that span. It is the standard discrete, non-compounded return measure applied to a 52-period lookback on any bar frequency (minutes, days, weeks, etc.).
    Intuition: It answers: 'how much did the price move, in percentage terms, over the last 52 bars?' A 52-period simple return of 0.05 means the price is 5% higher than it was 52 periods ago.
    Mechanics: Divide the current closing price by the closing price 52 periods earlier and subtract 1; the result is a fraction (multiply by 100 for a percentage). Standard implementation convention: pandas Series.pct_change(periods=52), which leaves the first 52 values undefined (NaN) because 52 prior observations are required; the span covers 52 sampling intervals and therefore uses 53 prices. Use split- and dividend-adjusted prices for a total-return measure; raw closes yield a price return only.
    Failure modes: The measure depends only on the two endpoint prices, so a single outlier, stale quote, or illiquid print at either end distorts it, and it ignores the path taken in between. Overlapping 52-period windows also induce strong serial correlation in the resulting series, which invalidates naive statistical tests.
    Misconceptions: A 52-period simple return is not 52 times the average one-period return (multi-period gains compound: R = product of (1 + r_i) - 1), and a +x% move is not cancelled by a later -x% move. It also excludes dividends unless adjusted prices are used, so it understates the total return of income-paying assets.
    Example: On daily bars, a stock closed at $92.00 52 trading days ago and closes at $94.30 today; the 52-period simple return is 94.30/92.00 - 1 = +2.50%.
    R_t(52) = P_t / P_(t-52) - 1 = (P_t - P_(t-52)) / P_(t-52), where P_t is the (adjusted) closing price at observation t and 52 is the lookback in periods. Multiply by 100 to express the result as a percentage.
    Aliases: 52-period return, 52-period holding period return, 52-period price return

    63-period simple return #

    The simple (holding-period) return of an asset between the current observation and the observation 63 periods earlier, expressed as the fractional change in price over that span. It is the standard discrete, non-compounded return measure applied to a 63-period lookback on any bar frequency (minutes, days, weeks, etc.).
    Intuition: It answers: 'how much did the price move, in percentage terms, over the last 63 bars?' A 63-period simple return of 0.05 means the price is 5% higher than it was 63 periods ago.
    Mechanics: Divide the current closing price by the closing price 63 periods earlier and subtract 1; the result is a fraction (multiply by 100 for a percentage). Standard implementation convention: pandas Series.pct_change(periods=63), which leaves the first 63 values undefined (NaN) because 63 prior observations are required; the span covers 63 sampling intervals and therefore uses 64 prices. Use split- and dividend-adjusted prices for a total-return measure; raw closes yield a price return only.
    Failure modes: The measure depends only on the two endpoint prices, so a single outlier, stale quote, or illiquid print at either end distorts it, and it ignores the path taken in between. Overlapping 63-period windows also induce strong serial correlation in the resulting series, which invalidates naive statistical tests.
    Misconceptions: A 63-period simple return is not 63 times the average one-period return (multi-period gains compound: R = product of (1 + r_i) - 1), and a +x% move is not cancelled by a later -x% move. It also excludes dividends unless adjusted prices are used, so it understates the total return of income-paying assets.
    Example: On daily bars, a stock closed at $103.00 63 trading days ago and closes at $101.97 today; the 63-period simple return is 101.97/103.00 - 1 = -1.00%.
    R_t(63) = P_t / P_(t-63) - 1 = (P_t - P_(t-63)) / P_(t-63), where P_t is the (adjusted) closing price at observation t and 63 is the lookback in periods. Multiply by 100 to express the result as a percentage.
    Aliases: 63-period return, 63-period holding period return, 63-period price return
